CAT NeoVERSE · Vortex OT-Cloud

3U · MicroCloud OT-Cluster

SYS-531MC-H8TNR

An 8-node Micro-Cloud cluster distributing OT-Cloud services in a single 3U chassis.

  • 8 nodes · single-socket
  • Xeon 6300 / EPYC 4005
  • Up to 128GB DDR5 / node
  • 2200W Titanium redundant

Download Datasheet   Request a demo

The 3U MicroCloud packs eight independent single-socket nodes into one chassis — the building block of the OT-Cloud cluster. Each node runs a slice of the fabric, so edge, profile, file, zone and cache services scale horizontally with immune-grade isolation.

Technical Specifications

Form Factor
3U rackmount, 8-node MicroCloud cluster
Processor
8 × single Intel® Xeon® 6300/2400/2300 or AMD EPYC™ 4005/4004 (LGA-1700, up to 95W TDP) · Intel® C266
Memory
Up to 128GB ECC UDIMM DDR5-4400 per node (4 DIMM sockets)
Storage
2 × front hot-swap 3.5" SATA3 or hybrid 2.5" SAS/SATA3/NVMe U.2 per node
Expansion
Per node: 1 × PCIe 5.0 x8 LP + 1 × PCIe 4.0 x8 Micro-LP
Power
2200W redundant Titanium-level high-efficiency
Temperature
Commercial 0°C to 40°C
